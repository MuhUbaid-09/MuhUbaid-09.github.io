My Role

Tools & Pipeline Programmer

Built an internal node-graph authoring suite and runtime interpreter for a narrative RPG team so writers could build branching quests, inspect variable conditions, and catch broken localization keys before entering Play Mode.

What I Did

  • Created a dockable GraphView editor window supporting dialogue nodes, blackboard condition branches, and event triggers.
  • Implemented a compile-time graph validator that flags orphaned nodes, missing voice-over clips, and invalid variable keys on asset save.
  • Serialized node graphs into flat contiguous ScriptableObject arrays for O(1) index jumps at runtime without reflection.
  • Added live Play Mode node highlighting so writers can watch active conversation paths light up in real time.
