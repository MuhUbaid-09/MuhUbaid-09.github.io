My Role

Lead Gameplay & Combat Systems Programmer

Owned the player character controller, melee/ranged combat state machine, and the frame-ring buffer that allows players to rewind enemy positions by 3 seconds without desyncing physics or hitboxes.

What I Did

  • Built a sub-stepped kinematic 2.5D character controller with 110ms input buffering and ledge-snap forgiveness.
  • Implemented a zero-allocation circular state buffer recording 180 ticks of transform, velocity, and animator hashes per enemy.
  • Created a custom Unity Editor Timeline track for combat designers to author hitbox active frames, cancel windows, and camera impulse shakes visually.
  • Wired a reactive HUD using UI Toolkit with pooled damage numbers and off-screen threat indicators.
  • Profiled and eliminated GC spikes during wave spawns by moving projectile and VFX lifecycles to pre-warmed object pools.

Systems I Built

// architecture & debug captures

01

180-Tick Rewind Ring Buffer

Records fixed-tick snapshots into a pre-allocated struct array per agent. Rewinding scrubs backward through snapshots and interpolates transforms without triggering garbage collection.

02

Hitbox & Cancel Window Inspector

Custom EditorWindow that renders animation clip frames alongside collider gizmos so designers can drag active parry and dash-cancel ranges directly in the Scene view.

03

Input Buffer & Coyote Queue

Stores incoming attack and dodge actions in a priority ring queue with configurable expiry timestamps, firing immediately on the first valid cancel frame.
